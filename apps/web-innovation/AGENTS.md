# web-innovation 开发指南

适用于 `apps/web-innovation/`，同时遵守根目录 `../../AGENTS.md`。修改前阅读本目录 `CONTEXT.md`。

## 开发约束

- 本应用作为前端原型开发，不接入真实后端；需要的数据一律使用 Mock。
- 优先完善页面布局、交互、校验和流程演示，不引入真实业务系统依赖。
- 复用 Ant Design Vue、Vben 组件和当前表单、VXE 表格适配。
- 页面放在 `src/views/`，功能路由放在 `src/router/routes/modules/`。
- 本应用源码使用 `#/` 别名，公共能力使用 `@vben/*`。
- 文案、菜单与页面标题遵循现有多语言和路由配置方式。
- 将 Mock 数据、类型和模拟操作从页面展示逻辑中分离，保持数据标识稳定。
- 需要请求行为时扩展 `../backend-mock/`，不把请求基地址或代理切换到真实后端。
- 保存、删除、提交、审批等操作只更新本地模拟状态，并提供明确的交互反馈。
- 浏览器持久化使用本应用专属键前缀，提供可恢复的初始演示数据。
- 专属功能在本应用内实现；修改共享包或共享 Mock 时检查其他应用的兼容性。

## 验证与维护

- 代码修改运行 `pnpm --filter @vben/web-innovation run typecheck`。
- 涉及打包或运行配置时运行 `pnpm build:innovation`。
- 检查页面导航、关键交互、Mock 数据变化以及刷新后的状态是否符合预期。
- 文档修改仅检查内容与格式；重要功能和数据策略变化同步更新 `CONTEXT.md`。
