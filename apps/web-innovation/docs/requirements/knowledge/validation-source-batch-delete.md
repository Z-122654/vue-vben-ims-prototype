# 关联来源子表批量删除验证

日期：2026-11-04。依据用户确认的“统一关联来源子表的新增与批量删除操作”方案，仅修改本地原型与需求文档，不提交代码。

## 实现范围

- 三类子表统一“新增、删除、刷新”，当前页复选框全选／半选，翻页及切换模块清空勾选；未选、只读及文件读取期间按规则禁用。
- 删除前校验角色、状态及全部所选有效关系，编辑态一次性标记移除；不删除正文、附件或原模块记录，主表保存才持久化。子表刷新保留待保存的新增与删除。
- 主子表只显示有效关联，取消蓝色说明、展开列及行内移除按钮。独立关联记录弹窗承载有效／已移除关系、时间、范围、版本及管理员复核；必要的材料清理单独确认影响。
- 沿用关联结构、移除标记和保存／发布限制，未迁移或重置演示数据。

## 浏览器验证

Chrome，知识管理员身份，在既有验收草稿“三类关联子表验收示例”中验证：

1. 三个页签分别显示对应业务列及“新增、删除、刷新”，删除未勾选时灰底灰字；无蓝色说明，无主子表展开列。
2. 交流页签追加两条演示来源并保存；单选出现半选，表头全选当前页三条；切换课题和竞赛再返回交流，勾选清空。
3. 勾选新增的两条并删除，立即从表格隐藏，无材料选择弹窗；子表刷新仍只剩原有效关系。
4. 保存、关闭、浏览器重载后重开，删除结果保留。关联记录仍包含两条已移除关系，可展开查看关联人、时间、范围和版本；未带入材料的移除关系显示已清理／无需复核。关闭关联记录回到交流页签。
5. 视觉核对了当前页表格、横向列布局及追溯表单。三个原有有效来源保留，未发布知识、未改动源业务记录；新增后移除的演示关系仅留历史追溯。

跨页选择、保存失败、放弃关闭、遗留正文／附件保护及权限异常由自动测试覆盖，未在浏览器逐一制造全部异常。
