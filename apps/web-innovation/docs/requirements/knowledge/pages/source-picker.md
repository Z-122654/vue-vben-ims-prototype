# 来源选择与带入弹窗（知识库第2批）

[返回总需求](../overview.md) · [知识明细](knowledge-detail.md) · [共用引用规则](../source-rules.md)

关联 KNOWLEDGE-REQ-003～009、AC-003～007。依据SRC-K06～K09；本页已实现，验证见[第2批记录](../validation-batch-2.md)。既有确认原则见共用引用规则；本页操作顺序、筛选与预填方式为本轮页面实现，Q-004～010已确认，相关身份、权限与失效处理按确认结论执行。

## 使用角色与入口

- 知识管理员在“知识管理”点击“从已有资料整理”：选择来源，再选择新建知识或关联已有知识。
- 知识草稿／已下架明细的“关联来源”中，各模块子表点击“新增”：固定当前模块和目标知识，选择一条后直接建立编辑态关联，不经过内容选择和带入预览。已发布知识先下架才能修改。
- 已关联行“补充带入”继续使用完整内容选择及预览流程，保留已有正文、回复和文件范围。
- 源页面“整理为知识”快捷入口：预选当前源对象，进入同一选择流程。只有知识管理权与来源资格同时满足才显示；当前人在源模块的管理员／专家身份不能替代知识管理权。
- 普通员工不提供来源选择入口。入口不可见不能替代动作时权限校验。跨模块身份依Q-004；源资料不具备资格时给出说明，不自动创建空知识。

## 弹窗结构

采用 IMS 大尺寸弹窗，工具栏操作，数据放入具名面板。关闭子弹窗返回知识明细原页签或原列表，并保留父级未保存内容、筛选、分页。遮罩不关闭；切换来源模块保留或清除已选内容须明确提示，不悄悄丢失选择。

以下完整流程适用于“从已有资料整理”、源页面快捷入口及“补充带入”；子表“新增”仅使用固定模块候选列表，查询／重置／分页后点击“选择”即返回父表单。

1. **选择来源**：交流研讨／课题攻关／创新竞赛三个页签；每次处理一个来源对象，可重复追加。
2. **选择内容**：基本信息只读表单，正文候选及成果／回复子表，附件选择子表；不使用未经筛选的原记录整表导出。
3. **目标与带入预览**：选新建或已有知识，选择“仅关联／关联并带入”，核对将修改的字段及选定文件，最后确认到编辑表单。

这些为同一流程内的区域／步骤，不新增独立业务菜单，不必额外生成三个路由页面。

## 筛选及候选表格

| 条件／列 | 数据与默认 | 校验及展示 |
| --- | --- | --- |
| 来源模块 | 首次从管理列表进入可选；快捷入口固定预选模块 | 只查询本模块有权限且符合引用状态的对象 |
| 来源编号／名称关键词 | 用户查询，默认空 | 只检索可访问候选，不匹配隐藏原文或未选内部文件 |
| 作者／负责人、部门 | 各模块对应人员及部门，默认全部有权范围 | 竞赛取有效公示负责人；交流主题作者和回复作者分别表达 |
| 来源状态及实际时间 | 已发布／已结题／已公示等对应事实 | 来源状态只读；显示实际发布、结题或公示时间，不当作知识时间 |
| 关联知识情况 | 当前对象是否已有知识关联 | 显示有权管理的目标名称与内容状态，避免仅检查已发布条目 |
| 选择／查看 | 当前候选操作 | 查看及进入下一步重新检查源资格，异常保留选择器并刷新问题行 |

课题候选表分别列出整体正式结题资料和具体成果行，可按课题名称查询。竞赛候选表列出当前有效公示的获奖项目，可按所属活动名称查询，零获奖不产生候选。交流先选主题，再按需选有效回复；显示采纳标识，不默认全选答案或附件。

## 内容、文件和目标字段

| 字段／子表 | 必填、默认与归属 | 行为 |
| --- | --- | --- |
| 来源对象 | 必选，一个当前对象 | 保存稳定关联，不能只保存名称或列表序号 |
| 回复／成果选择 | 依来源适用；不强迫课题必须存在成果行 | 显示选定对象的作者／负责人及正式正文，隐藏不符合范围项 |
| 正文候选 | 仅关联时不带入；带入时明确选择部分 | 只读预览供选择，带入后在知识表单整理；不解析Word／PDF |
| 附件子表 | 默认全部未选；选填 | 名称、格式、大小、原上传人／时间、所属主题／回复／课题／项目、可带入说明；无权限文件不列出 |
| 随知识发布确认 | 选择源文件时必须明确确认；默认未确认 | 明示文件将成为知识独立副本并供知识读者查看，不默认为仅内部链接 |
| 处理方式 | 新建知识／关联已有知识；从明细进入时固定已有目标 | 不直接写入源记录。已发布目标提示先下架，不自动下架 |
| 目标知识 | 关联已有时必选；按编号、标题、类型、状态查找 | 仅知识管理员可维护目标；同名不自动合并，不能选无权或已不存在目标 |
| 带入方式 | 默认仅关联；需要资料时明确选择关联并带入 | 新建仅关联可继续填写知识；仍须满足保存标题及发布规则，不生成空记录 |
| 字段动作 | 每项显示来源值、目标当前值、保留／追加／替换 | 已有字段默认保留，正文允许追加或明确替换；标量字段不做无意义追加。人员规则见Q-005 |

字段映射唯一见[共用引用规则](../source-rules.md#第2批内容带入映射)。源人员、文件上传人、知识整理人不能混用；来源时间和知识实际关联／发布时间分别记录。成果／案例依然需要统一正文，类型补充字段不会代替它。

案例在“目标与带入预览”中按需将已选正文对应到问题描述、处理方法及实施效果，再明确选择字段动作；不默认认定回复已验证。补充同源时不得取消仍被知识使用的正文范围。清理材料并移除后重新关联，使用当前有效选择，不恢复失效回复。合法确认带入后发生失效可暂存草稿，但仍须解决问题后发布（SRC-K10）。

取消本次选择的回复时，同时清理该回复的正文、文件及案例对应选择，不保留界面不可见的待带入项。已保存来源的范围保护继续执行。

## 操作条件与异常反馈

| 操作 | 前置条件 | 结果／失败 |
| --- | --- | --- |
| 查询／重置 | 当前身份和源权限有效 | 返回授权候选或空表；读取失败区别于没有资料，提供重试，不重置原模块 |
| 查看来源／原文件 | 源访问资格仍有效 | 打开获准内容，关闭返回选择器；失效仅提示，不用旧缓存展示内部内容 |
| 确认选定内容 | 至少一个合格来源对象；选定回复／成果及文件仍存在可访问 | 进入预览；不存在或失权指出问题对象，不选择其他对象替代 |
| 确认带入 | 目标可编辑；必要文件公开确认；来源重新校验；复制读取结束 | 只修改知识编辑态并列明带入结果；重复提示依共用规则；不自动保存、下架或发布 |
| 取消／关闭／Esc | 有尚未应用的选择或正在复制时提醒 | 放弃只取消本次带入，保留父表单原内容；终止读取后禁止迟到回写 |
| 知识保存／发布 | 返回主明细后执行；全部原校验继续有效 | 保存正文、选定附件和关联一起成功；失败保留输入，定位来源行或文件；失效草稿处理依Q-007、008 |

失败示例文案应指向原因：“该来源已不可用于整理，请重新选择”“无权查看当前材料”“该文件暂不支持带入”“该来源已有知识关联，请先核对”。不得在无权错误中泄漏原资料标题、文件名或审批意见。

## 快捷入口位置

以下入口已接通同一个选择器，不改源模块原有主流程。

| 源页面 | 建议入口 | 预选范围 |
| --- | --- | --- |
| 交流主题明细 | 已发布主题工具栏“整理为知识” | 当前主题；回复继续人工选择，采纳答案不自动带出全部文件 |
| 课题明细的结题资料 | 已结题资料面板工具栏；具体成果行可在共用选择器中选择 | 当前课题正式结题资料及指定成果行 |
| 公示明细获奖名单 | 符合资格的项目行“整理为知识” | 当前有效公示的该项目，不选择整个活动全部项目 |

没有知识管理权时不显示快捷入口；有知识管理权但没有源资格也不显示。入口状态在打开与确认时复验，不自动改变全局演示身份。关闭知识编辑返回原来源弹窗及页签。

## 验收

共用规则AC-003～007覆盖权限、状态及重复。本页补充AC-006：从管理列表与知识明细两个入口分别选择同一来源，得到相同字段／文件范围；取消预览不改父表单；复制失败不部分带入；存在同名知识不自动合并；源快捷入口不直接发布；关闭后保持原列表及父页签。执行结果见[第2批验证](../validation-batch-2.md)，自动测试和浏览器检查分别记录。

## 直接添加关联（2026-11-04 用户确认）

三类子表使用对应业务字段作为候选列，来源权限和资格继续复用统一校验。每次选一条，可反复追加；没有合格候选显示空表，读取失败单独提示。选择时再次校验最新资格，不直接写入存储、不复制正文附件。重复有效关系提示“该来源已关联，请勿重复添加”；已移除但仍有遗留材料时，提示先清理或通过补充带入处理，不能覆盖原范围；已清理关系可按原规则重新关联。

取消直接选择不改变父表单，返回原内部页签。原管理列表及源页面整理入口保留完整流程，不受固定模块模式影响。
