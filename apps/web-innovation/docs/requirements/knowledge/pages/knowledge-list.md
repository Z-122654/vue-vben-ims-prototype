# 知识检索与管理列表

[返回总需求](../overview.md)

> 关联 KNOWLEDGE-REQ-001、002、004、010。

## 页面结构和范围

知识检索面向登录员工，只显示已发布条目。全部／成果／案例／文档按类型切换，同源列表；知识管理仅知识管理员进入，显示可管理的草稿、已发布、已下架。筛选面板、操作栏、表格和分页沿用IMS。

| 条件／列 | 含义及来源 | 方式／默认 |
| --- | --- | --- |
| 标题／搜索词 | 知识标题、摘要、关键词、已录入正文 | 文本检索，默认空；不搜索源材料隐藏字段或文件全文 |
| 知识类型 | 成果／案例／文档 | 类型页签或单选，默认全部 |
| 专业分类 | 知识专业领域 | 分类选择，候选可复用交流专业词表；仍为知识自身分类 |
| 整理人、发布时间 | 知识整理和发布事实 | 人员／日期筛选，不与源作者及源发布时间混淆 |
| 内容状态 | 知识草稿、发布、下架 | 管理入口适用；普通员工固定已发布 |
| 来源模块 | 交流、课题、竞赛、无关联来源 | 管理筛选；多个来源可命中多个类型，行不重复；无关联不等于最初手工登记 |
| 来源需复核 | 来源变化提醒 | 管理入口使用，不作为知识内容状态 |

列表建议展示编号、标题、类型、专业、摘要、整理人、发布时间；管理列表增加状态、复核提醒及操作。具体列宽与分页大小属于实现选择，不写成业务要求。

## 操作

普通员工打开[只读明细](knowledge-detail.md)。管理员可新增知识、从已有资料整理、打开管理明细及按规则发布／下架。来源选择只返回有源访问资格的内容，不能先列出隐藏标题再禁止点击。

查询和重置始终在授权范围内；打开关闭明细保留筛选页码。首版没有已确认的导出模板，不自动增加批量下载全部附件能力。跨模块快捷入口在引用阶段完成前不显示。

## 第1批界面范围（历史交付记录）

- 类型以全部／成果／案例／文档页签即时切换，切换回第1页；查询按钮应用其他条件，重置清空全部查询及类型条件。
- 列表显示编号、标题、类型、专业分类、摘要、整理人、最近发布时间和明细操作；知识管理另显示内容状态。按最近发布时间（未发布取更新时间）倒序，同值按稳定标识排序。
- 知识检索对管理员也仅显示已发布条目；新增入口位于知识管理。管理员可从获准的明细执行发布管理，普通员工没有管理操作。
- 本批全为手工登记，隐藏“来源类型”“来源需复核”筛选及来源整理按钮，不将尚未实现的功能作为可用入口。
- 查询覆盖标题、摘要、关键词、专业、统一正文、适用场景及当前类型的补充正文；不搜索附件文件内容、其他类型残留字段或处理记录。

## 第2批增量

依据SRC-K06～K09；本轮已接通来源选择和复核。保持既有两菜单与类型页签，不新增“交流知识库／课题知识库／竞赛知识库”重复列表。

- 知识管理工具栏增加“从已有资料整理”，打开[来源选择弹窗](source-picker.md)，手工新增继续保留。没有管理权时不显示，也不能通过直接调用完成关联。
- 管理筛选增加“来源模块”（全部／交流／课题／竞赛／无关联来源）和“来源需复核”；默认全部。此处“无关联来源”表示当前无关系，与历史“手工登记”创建方式不同：手工知识后来可关联资料，从来源建立的知识解绑后也可能无关系。
- 多来源知识命中任一符合模块条件只返回一条；默认不检索源原文、内部附件名或处理意见。知识主表中已明确发布的内容仍按原搜索范围查找。
- 管理列表增加复核提示；待复核与暂无法核对不能混成同一状态，具体计算及处理依Q-008、010。普通检索不展示管理员待办或失权源摘要。
- 管理员“打开已有知识”能找到草稿、已发布、已下架条目；状态依然决定能否更改。给已发布条目加关系须先下架，选择器不得自动下架。
- 普通员工点明细依然是同源只读表单，关联来源显示依Q-006；无源权限不影响已经发布的知识正文和独立副本访问。父列表筛选和分页在关闭明细后保持。

复核检查时机、来源权限失败提示及新提醒处理见[共用规则](../source-rules.md#权限检查和复核规则)，已确认细节集中在[总需求](../overview.md#第2批细节确认记录)，不在本页复制规则。

验收增量：AC-001覆盖手工后续关联、多来源去重筛选和无关联来源筛选；AC-006覆盖管理入口、目标选择和取消；AC-007覆盖复核提示及无权限来源信息隐藏。涉及Q项的预期已依SRC-K08确认；执行结果见[第2批验证](../validation-batch-2.md)。

## 草稿知识删除（2026-11-04 用户确认）

- “知识管理”列表操作列增加“删除”，仅知识管理员且记录当前为草稿时显示；知识检索、普通员工、已发布和已下架记录不提供该按钮。
- 点击后确认具体知识标题，并说明删除本条草稿及其知识附件、关联记录，不影响原交流、课题、竞赛资料。取消不改变数据；确认后即时保存删除，无须再打开明细保存。
- 执行时重新读取最新数据，检查管理权限、记录存在、修订号及草稿状态，避免删除已被其他窗口修改或发布的知识。失败保留原记录并提示，可刷新后重试；写入失败不先移除列表行。
- 成功后保留筛选条件及类型页签；当前页超出剩余页数时退至最后有效页。刷新后不恢复被删除草稿，旧明细不能重新保存恢复该记录。
- 本功能删除整条知识，与“关联来源”子表的编辑态删除不同；不增加回收站或新状态。

验收：管理员删除／取消、员工及非草稿限制、确认期间发布或修订变化、存储失败重试、刷新保留、其他来源模块不变。记录见[草稿删除验证](../validation-draft-delete.md)。
