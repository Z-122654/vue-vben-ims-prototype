# 技术交流研讨首版原型验证

> 本文保留首版实施时的验证事实；知识库引用已在后续批次接通。当前核对与验证见[持续核对记录](audit-iterations.md)，不以首版“未实现”说明判断当前能力。

日期：2026-11-01。依据：SRC-E06，用户确认细节建议并授权实现交流模块，不提交代码。

## 实现范围

- 交流中心、我的交流、交流管理，同源列表的编号、标题、类型、专业、人员、部门、日期、内容／问题状态及本人关系筛选。
- 交流明细采用大弹窗，主题信息、交流回复页签；基本信息表单、附件及回复子表。子回复弹窗关闭返回原页签。
- 草稿保存、发布、撤回、历史保护、回复／引用、采纳／取消、管理员有理由下架、恢复及处理记录。
- 全员跨部门讨论；私人草稿仅作者可见，管理员也不可访问。公开只读界面与作者编辑同源，管理操作不改写正文。
- 主题和回复附件分别归属，Word下载、PDF／图片预览，关闭取消读取、迟到结果丢弃、读取期间保存发布禁用。
- 独立本地存储、修订号检查及保存失败原子性；保留既有竞赛和课题数据。

## 浏览器验证

使用正在运行的本地开发应用 `http://localhost:5666/exchange/center`，通过正常页面操作验证；未重置其他模块数据。

| 身份／场景 | 观察结果 |
| --- | --- |
| 陈嘉宁（管理员）查看已发布问答 | 表单只读，操作栏无重复标题状态；回复子表能看到有效／已采纳及已下架回复，具有下架、恢复和处理记录入口 |
| 林知远（主题作者）查看同一问答 | 原文只读，已有回复时撤回置灰；隐藏其他人的下架回复，有效答案可取消采纳／重新采纳，无管理员下架入口；交流管理菜单隐藏 |
| 作者取消采纳、再采纳 | 列表从已解决变为待解决，再恢复已解决；原回复保留 |
| 作者新建“交流原型验收：巡检记录经验” | 仅标题保存成功；缺交流类型发布定位错误并保留输入；补齐类型、专业及正文后零附件发布成功 |
| 周亦安（其他部门员工）浏览与回复 | 主题只读，无主题修改／下架入口；回复自动带出本人及部门，提交后返回交流回复页签，显示新增记录 |
| 浏览器刷新 | 新主题、回复、演示身份保留，回复数量和发布时间保持一致 |
| 管理员下架／恢复验收主题 | 下架原因填写后主题从交流中心消失；恢复后重新显示，回复和首次发布时间不丢失 |
| 表单与子表视觉 | 白底蓝色面板、三列主表及跨行正文、附件空表格、内部滚动、父子大弹窗符合当前IMS规范 |

浏览器验收产生的虚构主题及回复保留，便于直接查看。初始种子仍为6条主题；“重置演示”仅恢复本模块。

## 边界及未覆盖项

- 附件读取并发、失败、放弃、下载字节一致性由组件测试覆盖，本轮未在真实浏览器上传个人文件或重复验证全部格式预览。
- 存储配额失败和跨页签旧修订由自动测试模拟；原型仍为浏览器本地演示，不代表正式后端鉴权或多用户事务。
- 本轮浏览器检查为当前桌面视口，未覆盖全部移动设备尺寸。
- 知识库及来源引用未实现，EXCHANGE-AC-006留待第三批，不提供无效转知识库按钮。
