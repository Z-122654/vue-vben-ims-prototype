# 交流列表页面

[返回总需求](../overview.md)

> 同源页面：交流中心、我的交流、交流管理；关联 EXCHANGE-REQ-001、002、004、007。

## 入口、布局与范围

采用筛选面板、操作栏、带边框表格、分页。交流中心显示已发布内容；我的交流提供我发布的／我参与的关系筛选，实际提交过回复才计参与，同一主题仅一行；交流管理仅管理员进入，不显示他人私人草稿。作者可查看本人下架主题及对应原因，其他员工不可浏览下架内容。

交流中心和交流管理列表均不提供新增按钮，仅我的交流保留新增入口（2026-11-03用户确认）。新建打开空白主题弹窗，明细使用[统一表单](topic-detail.md)，返回保留筛选和页码。无权限入口隐藏，不能仅用只读控件暴露原文。

## 查询和列

| 条件／列 | 含义及来源 | 查询和默认 |
| --- | --- | --- |
| 编号、标题 | 主题系统编号与作者标题 | 文本查询，默认空 |
| 交流类型 | 日常交流／技术问答／经验分享 | 单选，默认全部 |
| 专业分类 | 运行、检修、热控、电气、安全环保、综合技术 | 单选，默认全部；不另增分类维护菜单 |
| 发布人、部门 | 主题作者身份，发布时保留归属 | 人员／部门筛选，默认全部可见范围 |
| 发布时间 | 首次发布实际时间 | 日期范围，默认空，草稿无发布时间 |
| 问题状态 | 待解决／已解决 | 仅问答适用；非问答列表为“—” |
| 内容状态 | 草稿／已发布／已下架 | 管理及我的交流按可见范围过滤 |
| 回复数量、最近回复时间 | 回复汇总，不等同浏览量 | 展示；普通列表只统计有效回复，历史回复仍阻止撤回 |
| 我的关系 | 我发布的／我参与的 | 我的交流适用，去重 |
| 操作 | 明细、适用的撤回／删除／管理入口 | 不作为查询字段 |

查询仅针对当前授权记录，重置不扩大权限。默认排序按最近回复或发布时间倒序，同值按稳定编号；排序不改变已确认业务状态。首版不增加列表导出要求。

## 操作与失败

新建仅建立本人编辑，不提供代填。查询应用条件，刷新重读当前数据，不重置演示内容。作者仅能删除从未发布草稿；撤回和下架使用总需求状态规则，执行时重验最新状态与权限。管理处理原因进入处理记录，不在列表新增审批节点。

## 验收

| 编号 | 前置条件与操作 | 预期 |
| --- | --- | --- |
| EXCHANGE-AC-001 | 作者有私人草稿，其他员工及管理员查看列表 | 他人看不到草稿；作者在我的交流可见 |
| EXCHANGE-AC-001 | 同一员工发布且回复同主题，筛选本人参与 | 仅一条主题；未提交回复不计入参与 |
| EXCHANGE-AC-001 | 筛选翻页后打开并关闭明细 | 返回原筛选与分页，不放大访问范围 |
| EXCHANGE-AC-002 | 曾发布后撤回的主题尝试删除 | 拒绝删除，保留历史；从未发布的本人草稿可删除 |

上述规则来源SRC-E02、E04。本轮实现与验证见[验证记录](../validation-prototype.md)。
