# 交流明细页面

[返回总需求](../overview.md)

> 关联 EXCHANGE-REQ-003～010；作者编辑、员工浏览、管理员处理使用同一大弹窗。

## 结构

顶部仅显示适用操作，不在右上角重复主题名和状态。主题信息页签包含基本信息、附件面板；交流回复页签包含回复记录子表。正文放入表单，不使用另一套文章页面。处理记录通过独立入口打开面板及表格，不伪造审批流程图。

## 字段

| 字段／面板 | 语义及类型 | 来源／默认 | 必填及编辑 |
| --- | --- | --- | --- |
| 标题／基本信息 | 单行主题名称，跨较宽位置 | 作者填写，初始空 | 保存及发布必填；草稿作者可改 |
| 编号／基本信息 | 稳定业务编号 | 系统生成，格式待定 | 只读，不因撤回重发变化 |
| 交流类型／基本信息 | 分类枚举 | 三种类型中选择 | 发布必填；草稿可改 |
| 专业分类／基本信息 | 技术专业分类 | 候选见列表 | 发布必填；草稿可改 |
| 正文／基本信息 | 多行交流内容，跨整行 | 作者填写，初始空 | 发布必填；已发布只读 |
| 发布人、部门／基本信息 | 作者与所属部门 | 当前登录人带出 | 自动，只读，不代填 |
| 内容状态／基本信息 | 草稿、已发布、已下架 | 操作决定，新建草稿 | 自动，只读 |
| 问题状态／基本信息 | 待解决、已解决 | 问答发布后待解决，采纳操作改变 | 仅问答展示，不人工选状态 |
| 首次发布时间、更新时间／基本信息 | 实际业务事件时间 | 对应成功操作记录 | 只读，未发生不补造；重发保留首次时间 |

纯空白视为未填；未知长度限制不擅自设定。保存只检查标题及已填字段合法性；发布检查全部发布必填项。管理员不能通过下架管理入口改写作者原文。

## 操作

| 操作 | 条件 | 成功及失败处理 |
| --- | --- | --- |
| 保存草稿、发布 | 作者草稿；附件读取结束 | 按总需求流转；错误定位字段，正文及附件不丢失，不部分保存 |
| 撤回 | 作者、已发布且没有回复 | 回草稿，保留发布历史；含下架回复在内的所有已提交记录均阻止撤回 |
| 新增／引用回复 | 当前已发布，登录员工 | 打开回复弹窗；下架主题的已打开编辑也不能提交 |
| 采纳 | 问答作者、他人的有效回复 | 一次仅一条；已有采纳需先取消，不静默覆盖 |
| 取消采纳 | 问答作者、有当前采纳 | 恢复待解决，保留历史；不删除回复 |
| 下架／恢复 | 交流管理员 | 下架须原因；恢复不自动恢复采纳，主题恢复不恢复单独下架的回复；主题下架后不允许继续互动 |
| 处理记录 | 按角色授权 | 显示操作、人员、时间、原因；作者可见本人主题／回复对应的处理记录，不全员暴露管理内容 |
| 关闭、刷新 | 当前访问者 | 有编辑／读取先确认；取消保留输入，放弃取消读取；关闭返回原列表 |

已解决仍可继续回复。非问答没有采纳入口。采纳回复被下架时，取消采纳与回复下架一并成功，失败不得留下“已解决但无有效答案”的部分状态。

## 附件与回复子表

主题附件独立于回复附件，选填，支持Word、PDF、图片；上传、删除仅草稿作者可用。附件名称、大小、上传人、上传时间、操作为表格列。已发布可见者可下载；Word无虚假预览按钮。未获准访问原文时也不可访问所属附件。

回复列表列：正文摘要、回复人、部门、回复时间、回复对象、是否采纳、操作。长正文经[回复明细](reply-detail.md)查看；子表新增不直接保存主题其他未保存编辑。引用关系使用稳定记录标识，不用行号或姓名替代。

读取时相应保存／发布禁用，关闭／刷新及Esc处理一致；组件卸载或放弃后禁止迟到回写。读取失败提示重试，不增加假附件。格式与容量失败须在保存前说明；正式容量参数仍待定。

只读正文和附件随最新可见记录更新，不能长期展示已撤换材料；未保存的可编辑草稿保留输入，保存时检查版本。附件预览关闭后返回原明细，预览未关闭时父明细不处理关闭／刷新／Esc。文件从当前可见清单移除时关闭其预览；主题失去访问资格时隐藏正文、附件及预览。

## 验收

| 编号 | 前置条件与操作 | 预期 |
| --- | --- | --- |
| EXCHANGE-AC-002 | 仅标题保存；缺正文发布；填完整后发布 | 可保存草稿，缺项阻止发布；成功记时间，失败不变更状态 |
| EXCHANGE-AC-002 | 无回复撤回重发；有回复后撤回 | 前者保留首次发布时间及历史；后者阻止 |
| EXCHANGE-AC-004 | 作者采纳他人答案，取消，再由管理员下架已采纳答案 | 问题状态与采纳同步；非作者和本人答案不能越权采纳 |
| EXCHANGE-AC-005 | 读取中关闭选择继续，再选择放弃；另一窗口下架主题后提交回复 | 继续保留；放弃不迟到回写；旧弹窗提交拒绝，无部分保存 |
| EXCHANGE-AC-005 | 另一窗口撤换材料，或当前预览文件已不可见 | 只读内容更新、失效预览关闭；关闭有效预览返回父明细，不连带关闭父弹窗 |

依据SRC-E02、E04；操作细节已按SRC-E06确认。实现与验收结果见[验证记录](../validation-prototype.md)。

## 知识库引用入口（2026-11-01）

按知识库SRC-K09接通“整理为知识”：交流已发布主题工具栏、课题已结题资料面板、有效公示获奖项目行提供入口。当前人须同时具有知识管理资格与本模块对应资料访问资格，不能借用其他模块缓存身份。调用共用来源选择器，明确字段动作和选定文件后进入知识编辑；不自动保存、发布或修改源记录。关闭知识编辑返回当前源明细及页签。

共享资格、署名、文件副本及复核规则统一见[来源引用规则](../../knowledge/source-rules.md)；实现验证见[知识库第2批记录](../../knowledge/validation-batch-2.md)。
