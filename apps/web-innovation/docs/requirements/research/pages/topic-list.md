## 页面与入口

两个菜单采用同源列表和[课题明细](topic-detail.md)，不复制课题记录。课题管理与审核供业务管理员使用；我的课题供员工以及兼任负责人、成员的管理员使用。布局为“筛选条件面板 → 操作栏 → 带边框表格 → 数量及分页”。

| 菜单 | 数据范围 | 操作栏 |
| --- | --- | --- |
| 课题管理与审核 | 本模块非草稿课题＋管理员自己创建的草稿；提交后撤回的草稿仅对其填报人／负责人开放 | 导出、刷新、收起筛选 |
| 我的课题 | 本人填报、负责或作为团队成员的非草稿课题；从未提交草稿仅填报人可见，撤回草稿填报人及负责人可见，普通成员不可见（SRC-009） | 新增课题、导出、刷新、收起筛选 |

命名调整（SRC-010）：原“课题管理”更名为“课题管理与审核”，用于明确管理员入口的用途；原路由、数据范围、功能和权限保持不变。两个菜单仍共用明细，按钮权限由当前人员与课题状态决定，不因入口不同而变化。

仅“我的课题”提供新增课题入口，打开空白课题表单（2026-11-04用户确认）。员工默认本人负责，管理员可指定负责人。没有访问权限的菜单／行操作隐藏；有权限但状态或资料不满足条件时禁用并说明原因，不只改变颜色。

## 查询和列表

| 项目 | 查询方式／默认值 | 列表展示和数据来源 |
| --- | --- | --- |
| 课题编号 | 文本模糊查询，默认空 | 系统生成编号，规则未定，不用行号作为业务编号 |
| 课题名称 | 文本模糊查询，默认空 | 课题主表名称；长名称能查看完整值 |
| 课题类别 | 单选，默认全部 | 主表类别；候选建议节能降耗、设备治理、可靠性提升、安全生产、管理改进、其他，不增加类别管理菜单 |
| 负责部门 | 部门选择，默认全部授权范围 | 随负责人带出；不等同于所有团队成员部门 |
| 课题负责人 | 人员选择，默认全部 | 主表负责人 |
| 当前状态 | 单选，默认全部 | 总文档中课题状态，不以日期推算 |
| 计划完成日期 | 起止范围，默认空 | 主表人工计划日期；逾期且未结束时提示 |
| 参与关系 | 仅我的课题；全部／我负责／我参与／我填报 | 可同时具有多种关系，列表每课题仅一行 |
| 已完成任务／总任务 | 首版不设专门筛选 | 从任务统计；无任务显示“尚未制定计划”，不等同总进度百分比 |
| 操作 | 不筛选 | 明细、适用的立项处理／结题处理、删除草稿 |

查询在授权数据中执行；重置只清空筛选，不扩大数据权限。默认建议按最近更新时间倒序，同时间按稳定记录标识排序；返回列表保留查询、分页。分页大小不作为正式业务规则。

## 操作与输出

| 操作 | 允许条件 | 结果与异常处理 |
| --- | --- | --- |
| 明细 | 可访问该课题 | 打开共用表单，编辑能力按角色与状态判断 |
| 立项处理 | 仅本模块业务管理员，对待立项且可处理的课题 | 打开课题信息页签；处理权限再次检查；已被处理则刷新提示 |
| 结题处理 | 仅本模块业务管理员，对待结题且可处理的课题 | 打开结题资料页签；不另建文章式审核页 |
| 删除草稿 | 本人填报且从未提交的草稿 | 确认后删除该草稿及其未提交从属资料；其他状态不提供删除 |
| 导出 | 当前菜单可见数据范围 | 导出当前筛选的全部结果而非仅当前页：编号、名称、类别、负责人、负责部门、状态、计划开始／完成、实际立项／结题、完成任务数与总数；不夹带附件内容或流程意见 |
| 刷新 | 当前菜单可访问 | 重新读取数据；保留筛选与分页，不重置 Mock |

导出格式暂建议沿用原型已有下载方式，正式格式待实际交付确认。不为了导出新增隐藏业务字段。

旧草稿兼容（SRC-011）：首次提交时间为空但仍有其他提交时间或提交立项历史的记录，属于曾经提交的草稿，不显示删除入口，删除操作也必须拒绝；未提交草稿的原有权限不变。对应 RESEARCH-AC-001、003，验证见[迭代记录](../iteration-audit.md)。

原型异常反馈（SRC-011）：本地读取失败时提示当前使用初始示例且原存储未覆盖；读取恢复并刷新成功后，显示实际保存数据并清除过期失败提示。此项仅说明本地原型行为，不规定正式系统存储方案。
