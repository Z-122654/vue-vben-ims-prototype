## 实施内容

- 共享基本信息表单包含申报要求，专家和管理员均显示填报人；字段、只读条件及附件权限保持独立。
- 申报的材料处理人／时间、获奖等级／公示日期，活动取消人／时间均为面板表单项；专家最近退回人、时间、原因归入“最近退回信息”面板，评审意见使用带必填标记的表单项。
- 流程图采用基本信息、材料审核流程、处理记录三面板，保持填报人提交、管理员审核的原流程；不增加部门或领导审批。计划期限、补交及退回评分弹窗沿用 IMS 视觉和关闭约束。
- 保存和提交同时校验活动名称80字、项目名称200字、类别100字、简介1000字。草稿仍只要求原有最小必填资料；非法长度不会部分更新原记录。
- 指标满分为1～100整数，指标标识有效且不重复，发布时名称非空不重复；不要求满分合计100。评分为0至单项满分、至多一位小数；暂存允许缺项但已填项必须合法，提交还要求全部评分和非空意见。
- 活动类型支持初始三类与自定义输入，保存去首尾空白后可从已存活动复用候选，发布不能为空。保留旧类型值，不增加数据迁移或清空演示数据；该方式尚不是带停用、排序等功能的独立字典管理。

## 验证边界

- 完整跨日期主流程通过业务自动化测试覆盖；浏览器按角色逐段验证关键操作，不宣称在同一条新记录上人工等待日期推进完成整条流程。
- 公示更正、附件确认、下载文件内容与筛选导出的详细检查沿用[第2批记录](validation-batch-2.md)，本批自动化回归，未重复真实 Word 上传或所有文件格式下载。
- 保留旧数据与评分，不为让数据符合新限制而自动截断或改写；历史非法配置若需重新保存，应由用户修正并通过当前校验。
- 本地 Mock 不等于生产后端鉴权、事务、存储和审计。正式附件配置、IMS 编号、业主 PDF 证书模板仍为 DEP-01～03，独立字典接入见 D-10；未实现或伪造正式系统集成。
