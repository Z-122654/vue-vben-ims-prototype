## 已实施范围

- 申报附件分为填报人拟公开、管理员确认公开。材料审核通过时逐份确认，历史已通过项目支持授权管理员补确认公开范围；普通浏览者只读取已确认文件。撤回、退回及材料修改清除旧确认，内部材料访问权不扩大。
- 支持零获奖公示，要求保存标题和说明正文；有未保存修改时阻止发布，提示先保存。未获奖不生成证书。
- 已公示／已结束结果通过专门更正操作维护，原因必填。保存独立草稿不改变有效公示；重新发布保留旧版快照、原因、处理人和时间；可放弃草稿。已结束活动更正后仍保持已结束，未增加重新评分流程。
- 只删除无任何申报的草稿活动、本人从未提交的草稿申报；已提交记录即使撤回也保留。取消活动必须填写原因，停止申报／评分且保留材料、历史及既有访问边界。
- 提交时保存负责人姓名及部门快照，重提更新；公示固定获奖资料供名单、项目基本信息及演示证书使用。目录改名、调岗或当前资料修改不自动改写旧版本。
- 申报及评审保留首次／最近成功提交时间，退回、撤回及暂存不抹除；再次提交更新最近时间。旧资料只从明确历史补齐，缺首次时间不以最近时间冒充。
- 申报数排除草稿、撤回、终止，通过数另列。名单及专家记录子表导出当前筛选全部结果，不限当前页；我的参赛导出包含六项资料及首次／最近提交、补交流程信息。
- 演示证书下载限定为活动授权管理员、该项目填报人及负责人；不因为下载证书而取得内部附件权限。仍使用带演示标识的 SVG，正式 PDF、模板与编号不在本批交付范围。

## 兼容与验证边界

- 已存旧附件的公开标记兼容为拟公开，文件内容、ID 和上传信息保留；普通用户需等待管理员确认。这是本批可见行为变化，不自动把旧标记伪装成管理员审核历史。
- 旧公示缺少版本时，以当前可用资料生成带“旧资料兼容快照”标记的版本并持久化；无法恢复的原始姓名、部门或首次时间不补造。已有用户编辑数据不重置。
- 这是浏览器本地 Mock 的规则验证，不代表正式后端鉴权、数据库事务、审计或文件存储已经实现。
- 未重做原始 `.doc` 上传、全部角色全部页面或生产规模数据验收；删除、取消、结束后更正、目录变化及评审重提边界主要由自动化测试覆盖。正式 PDF 未生成。
- 本批没有改变评分精度或字段长度规则；活动类型字典、评分业务层精度及长度校验、剩余面板表单一致性和全角色完整演示继续按 D-08～10 跟进；正式附件配置、编号和业主证书模板见 DEP-01～03。
