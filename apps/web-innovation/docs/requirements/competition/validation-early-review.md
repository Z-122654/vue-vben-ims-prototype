# 提前开启活动评审验证

日期：2026-10-27。依据：SRC-29；对应 COMP-REQ-008、014、016、023，更新 COMP-AC-041，保留原编号。

## 实施

取消开启评审时必须超过报名截止日期的检查；活动仍须报名中、管理员组织授权有效、至少一项审核通过、无待审核或退回修改项目、专家有效并通过本人项目回避。草稿、已撤回、已终止不阻止开启且不生成任务。

开启后立即停止报名、草稿保存／提交、撤回和材料修改；记录实际开始时间、锁定专家名单和参评材料，计划报名截止保持原值。确认提示明确停止报名及未提交／撤回项目不参评的后果。无接口、数据结构或旧数据迁移变化；上轮历史耗时和奖项空格问题不在本次修改范围。
