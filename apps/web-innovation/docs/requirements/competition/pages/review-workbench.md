## 用途、入口与数据范围

菜单“评审工作台”，供专家处理分配给自己的评审任务。一行对应一条项目与专家的评审关系；不是一行汇总所有专家结果。开启活动评审后按活动统一专家名单生成任务，不在此页认领或分配。

当前列表按任务所属专家过滤，所有任务状态均可查询，不只待办。非该专家不能看到其任务；授权组织范围内管理员从[活动明细专家评审记录](activity-detail.md)查看提交结果，不通过个人工作台获得所有专家草稿。

已确认业务管理员可从 IMS 人员目录跨部门自由选人，无需预先具备专家角色；被选人员在该活动开启评审、生成本人任务后可进入工作台处理任务，不应被旧演示角色条件拦截。同一人员可在另一活动作为填报人，仍按各活动的归属和任务校验，不授予未分配活动的评审权。本人项目回避已前移到申报提交和专家配置，审核通过及开启评审保留最终校验；规则见已确认 COMP-Q-002、SRC-13、SRC-30。

## 查询与列

| 项目 | 内容／来源 | 查询和展示 |
| --- | --- | --- |
| 编号 | 关联项目申报编号 | 顶部文本包含筛选；不是单独任务编号 |
| 项目名称 | 关联申报名称 | 顶部文本包含筛选 |
| 所属活动 | 关联项目所属活动 | 顶部单选筛选，列表展示活动名称 |
| 状态 | 任务状态 | 顶部待评审、评分暂存、已提交单选 |
| 项目负责人 | 关联申报负责人 | 列表展示，不能误显示填报人 |
| 计划评审截止 | 活动评审截止字段 | 已确认显示管理员设置的计划截止；逾期提示但不强制拦截本人提交，不自动推进状态；原型已提供“进度提醒”列及明细逾期提示，见 D-02 |
| 操作 | 评审或明细 | 未提交任务显示评审，已提交显示明细 |

完整列顺序：编号、项目名称、所属活动、项目负责人、计划评审截止、进度提醒、状态、操作。顶部查询、列筛选、排序和分页沿用[活动中心](activity-center.md)；初始查询为空。不出现总分、平均分、排名或其他专家评分列。

## 操作及异常

| 操作 | 条件 | 结果 |
| --- | --- | --- |
| 评审／明细 | 本人的任务 | 打开[专家评审弹窗](review-detail.md)；是否可编辑进一步检查活动是否评审中和任务是否已提交 |
| 查询、重置、刷新、收起／展开 | 工作台使用者 | 只影响列表展示，不改变任务状态 |
| 导出 | 当前身份的列表结果 | 按已确认规则导出所有筛选结果的业务列，不限当前页；现状CSV；不包含评分、评语、附件、其他专家记录 |

原型中已取消活动的任务仍可能留在工作台，打开后只读；“评审”行按钮文字不意味着一定可提交。已确认取消后停止评分，但保留相关专家本人任务历史只读可查，不能作为可执行待办（COMP-Q-007）。任务不存在或访问身份不符时提示无权查看，不回退为新建任务。
