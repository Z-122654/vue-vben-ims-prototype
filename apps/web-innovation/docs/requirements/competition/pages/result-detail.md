## 页面入口与结构

来自结果公示列表明细、活动明细“查看公示”、项目获奖结果“查看公示及证书”。大尺寸只读弹窗，标题“公示明细”；顶部仅关闭、导出名单，不在右侧另列业务名称和状态。

全部主数据置于“基本信息”面板；“获奖名单”为独立表格面板。证书预览在子弹窗打开，关闭返回公示；项目明细打开同源项目弹窗，返回保留父级上下文。

## 基本信息表单

仅活动已公示或已结束才可展示，其他状态／不存在给出提示。以下均为只读，不在本页修改或重新提交。

| 字段 | 业务类型／来源 | 必填／展示与注意事项 |
| --- | --- | --- |
| 公示标题 | 文本，管理员登记的公示标题 | 发布前必填，独占一行；不是活动名称替代品 |
| 活动名称 | 文本，取当前有效公示版本的活动名称；无版本时沿用所属活动名称 | 只读表单展示，与公示标题分别列出；旁边“查看活动”按关联活动标识打开活动明细，关闭后返回公示 |
| 组织单位 | 组织名称，来自活动组织单位 | 活动发布前已填 |
| 公示日期 | 日期，取成功发布公示时自动记录的实际时间之日期部分 | 已确认只读，不是发布前手填必填项；现成功发布时自动产生，旧日期保留，见 D-01、SRC-12、SRC-16 |
| 当前状态 | 活动状态 | 已公示或已结束，放在正文表单 |
| 异议反馈联系人 | 文本，沿用活动联系人 | 只读；沿用活动联系人，本期不另设异议工作流 |
| 联系电话 | 文本，沿用活动联系方式 | 只读；不得把演示号码当正式联系人数据 |
| 公示正文 | 多行文本，来自管理员登记 | 发布前必填，独占一行，长文完整显示 |

当前没有公示起止期、异议在线提交／处理表单、结果撤销入口；不能从“异议反馈”文字推断已存在异议工作流。目标按 COMP-Q-006 提供管理员专门更正；本期不增加固定公示天数或在线异议工作流。

## 获奖名单子表

| 列 | 数据来源与规则 |
| --- | --- |
| 项目名称 | 本活动已登记奖项的申报名称 |
| 类别 | 项目申报类别，保留自定义及旧类别 |
| 项目负责人 | 申报项目负责人，不能换成填报人 |
| 部门 | 公示发布时固定的项目负责人部门快照，不随目录调岗变化 |
| 奖项 | 管理员登记的本活动奖项名称，非根据分数自动推导 |
| 操作 | 项目明细、证书 |

SRC-17 按最新有效公示版本显示获奖项目，零获奖版本显示空名单及说明，未获奖不在名单中；排序仅表格排序，无业务排名含义。支持列筛选、排序、数量、分页。不公开专家分数、评审意见、内部获奖确认依据。

关闭参赛作品展示不会取消公示，也不会删除获奖名单。普通浏览者从项目明细进入时，沿用原获奖项目访问条件，统一查看全部基本信息只读表单与公开附件（SRC-14）；内部材料按填报人、管理员、任务专家授权区分。正式公开范围集中见 COMP-Q-004，本页不因“证书”或“项目明细”入口而扩大内部附件权限。

| 项目明细 | 打开对应申报的同源查看页面 | 能看公开结果不表示能下载非公开附件；无权限或不存在显示提示 |

证书现状内容：荣誉证书标题、项目负责人姓名、项目名称、活动名称、奖项、组织单位、公示日期、申报编号及演示标识。已有成果／专利不是竞赛奖项，不能代替获奖等级。证书现状不单列负责人部门；负责人及部门资料需与其他页面保持统一来源，正式模板是否显示部门由 COMP-Q-009 决定。

SRC-26：演示证书预览和下载共用同一排版结果。项目名称（最多200字）、活动名称（最多80字）及其他文字按行完整展示，后续区块与画布高度随实际行数调整，不能重叠、截断或省略名称。预览区域允许滚动，关闭后返回公示；特殊字符按文字处理。本次不改变证书访问权限、快照来源，不引入正式PDF、电子签章或业主模板。

已确认公示日期自动取实际发布日，因此证书所用公示日期也应与公示列表及明细一致，不另行手填。更正按 COMP-Q-006 保留旧版后重新发布，不通过改日期或普通编辑覆盖历史版本。

已确认正式模板由业主提供、编号沿用 IMS、PDF 下载、不含电子签章（COMP-REQ-028）。本期不自行增加独立证书撤销／重发流程；结果更正走保留旧版本的专门操作，证书资料必须取对应已发布版本。不得在需求中把演示SVG承诺成正式电子签章能力，也不加入用户原材料或真实联系方式作示例。

## 公示与证书的目标规则

COMP-REQ-013、024、028、030：公示面向公司内已登录且有模块权限者；零获奖结果也可发布，说明由管理员在正文自行填写，不新增字段或强制校验说明内容；标题、正文仍必填（SRC-23），获奖名单为空，获奖数为0，不生成证书。关闭参赛作品展示仍可查看已公示获奖项目全部基本信息表单与填报人设置公开的附件。

正式证书在管理员提交的获奖结果经全部领导同意并自动发布后生成，采用业主模板、IMS 编号和PDF，姓名取项目负责人，内容取已发布结果快照；本期无电子签章。下载仅限该活动授权管理员、该项目填报人和负责人；专家或普通浏览者不能仅因可看公示取得下载权，负责人也不因此获得内部申报附件权限。模板尚未提供不影响业务规则确认，但不能将演示SVG作为正式证书交付。

发布后普通编辑锁定；授权管理员专门更正须填写原因，保留旧版本并经全部公示审批人同意后自动发布。对外展示有效已发布版本；更正过程和历史依据供授权管理核对，不将内部确认依据开放给普通用户。
