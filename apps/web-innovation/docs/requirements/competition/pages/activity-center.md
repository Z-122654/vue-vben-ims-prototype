## 页面与入口

菜单“创新竞赛与成果评比管理 → 活动中心”。采用筛选条件面板、操作栏、带列筛选的活动表格、数量和分页。新增及明细打开[活动明细弹窗](activity-detail.md)，关闭后留在列表；新申报的唯一入口是列表操作列“申报”，打开[项目申报弹窗](entry-detail.md)，自动带入当前行活动且只读，不另选活动。

## 数据范围、查询与列

现按管理员获授权的组织显示草稿；已发布活动可普通浏览，取消活动仅限管理范围或本人相关申报／任务历史。已确认管理权限应按授权组织范围限定：管理员只能以管理权限查看、维护范围内活动，不能仅凭管理员身份读取范围外内部材料或执行管理操作；作为普通浏览者可见哪些已发布活动仍按公开范围规则处理，见 COMP-Q-004。报名范围控制“申报”行按钮及新申报资格，不由负责人选择替代。初始查询条件为空。

| 筛选字段 | 类型／来源 | 查询行为 |
| --- | --- | --- |
| 编号 | 活动自动编号，文本 | 输入包含匹配 |
| 活动名称 | 活动名称，文本 | 输入包含匹配 |
| 组织单位 | 组织选择项 | 单选精确匹配 |
| 状态 | 活动生命周期状态 | 单选；草稿、报名中、评审中、待公示、已公示、已结束、已取消 |

| 列 | 含义／数据来源 | 注意事项 |
| --- | --- | --- |
| 编号、活动名称 | 活动主记录 | 编号沿用 IMS，具体配置见 DEP-02 |
| 活动类型、组织单位 | 活动配置 | 类型不是申报项目类别 |
| 报名截止日期 | 活动报名截止 | 已确认计划报名截止，由管理员设置；截止当天仍允许普通报名，见 COMP-Q-001 |
| 申报数量 | 当前活动已提交且未撤回、未终止记录数量 | 包含待审核、退回修改、审核通过；审核通过数单独展示；SRC-17 已按此口径修正 |
| 状态 | 活动状态 | 已公示表示结果已发布，不表示开启作品展示 |
| 操作 | 明细、条件满足时申报／删除 | 非业务数据列 |

查询应用筛选条件；重置清空顶部与列筛选并回到第一页；收起只折叠顶部筛选区。列筛选在顶部筛选结果上继续过滤，多列取交集，现状为大小写不敏感的文本包含匹配。支持列排序和分页；无数据时显示空表及数量0。现状初始每页20条，可选10／20／50，不作为正式容量要求。

## 操作与结果

| 操作 | 显示／允许范围 | 结果与失败处理 |
| --- | --- | --- |
| 新增活动 | 具有对应组织管理权限的管理员 | 打开空白活动草稿；活动组织单位受授权范围约束，保存／发布再次校验 |
| 明细 | 当前列表可见记录 | 打开已有活动；记录失效或无权限时显示不可访问提示，不创建新记录 |
| 申报 | 当前登录人的部门在该活动参赛范围内，并满足报名状态与期限时提供；兼任专家／管理员不能绕过范围；已被选为本活动评审专家时按钮禁用，提示不能同时作为填报人参赛并联系管理员调整名单 | 唯一新申报入口；活动带入只读，负责人仅选登录人本部门且未被选为本活动专家的人员；提交／重提再次检查最新专家名单与填报人、负责人是否冲突，保存仍允许保留冲突草稿，直接入口或篡改参数不能绕过 |
| 删除 | 该活动处于管理员授权组织范围内、为草稿且无任何申报 | 确认后移除草稿；取消确认不改变数据；有申报、非草稿或越权均阻止操作 |
| 查询／重置／刷新 | 页面浏览者 | 刷新现状重新应用筛选；不是重新生成示例数据；不变更活动状态 |
| 导出 | 页面浏览者 | 当前顶部及列筛选后的全部结果，非仅当前页；字段同可见业务列，不导出操作列 |
| 收起／展开 | 页面浏览者 | 只改变筛选区显示，不清除筛选 |

导出当前使用 CSV；目标为当前顶部及列筛选共同过滤后的全部结果，不限当前页且不扩大可见权限（COMP-Q-010）。仅无任何申报的草稿活动可删除（COMP-Q-007）。演示身份切换和“重置演示”是演示设施，不是业务操作。

### 提前开启评审后的报名边界（SRC-29）

普通报名必须同时满足活动仍为“报名中”、部门范围及计划截止条件。管理员可在材料收口并通过专家校验后提前开启评审；开启后即使尚未到计划截止，也不再提供申报入口，已打开的草稿／撤回项目不能继续保存或提交，已通过项目不能撤回或修改材料。草稿、已撤回、已终止项目不生成评审任务，已有记录保留。参见[活动明细 COMP-AC-041](activity-detail.md#验收场景)。

2026-10-27 身份互斥校验前移（SRC-30）：本次申报入口、负责人及专家候选、提交／重提、名单保存，以及审核通过和开启评审的最终检查，按本页最新规则执行。历史验证记录保持原样，具体本轮证据见[身份冲突验证](../validation-expert-participation.md)。
