## 用途与范围

菜单“结果公示”，查询已发布的活动获奖结果。现状以活动为一行，显示活动状态已公示或已结束的记录；待公示、评审中、报名中、草稿、已取消均不在此列表。

**不按“参赛作品展示”开关筛选。** 关闭展示的活动，只要完成结果发布，仍出现在结果公示列表；开启展示也不会让尚未发布的结果提前出现。活动状态和作品展示是两个独立概念。

目标受众已确认为公司内已登录且有模块访问权限的用户，不提供互联网匿名访问（COMP-Q-004）；原型固定演示身份不代替正式授权。

## 查询、列和操作

| 查询条件 | 数据类型／来源 | 现状规则 |
| --- | --- | --- |
| 编号 | 活动编号文本 | 包含匹配；当前无独立公示编号 |
| 公示标题 | 已保存公示标题 | 包含匹配，不是活动名称搜索 |
| 组织单位 | 活动组织单位 | 单选精确匹配 |
| 状态 | 活动状态 | 单选已公示／已结束 |

列表列为编号、公示标题、活动名称、组织单位、公示日期、获奖作品数、状态、操作。获奖作品数取该活动有奖项的项目数量；已确认公示日期取成功发布公示的实际时间之日期部分，不再单独手填；当前取最新有效公示版本的实际发布日期，已按 SRC-16、SRC-17 实现。活动名称取所属活动名称，与公示标题分别展示；支持活动名称列包含筛选，导出公示目录时包含活动名称。顶部“公示标题”查询仍只匹配公示标题。初始查询为空，列筛选、排序和分页沿用[活动中心](activity-center.md)。

| 操作 | 条件及结果 |
| --- | --- |
| 明细 | 打开[公示明细弹窗](result-detail.md)；没有编辑入口 |
| 查询／重置／刷新／收起展开 | 更新筛选与表格显示，不发布或撤回公示 |
| 导出 | 现状导出全部筛选结果的业务列，不含操作列；为公示目录，不等于获奖项目名单 |

发布公示在[活动明细](activity-detail.md)由管理员操作，本页不能新增或直接发布。记录未发布／不存在时进入明细只显示不可用提示。列表导出目标为当前筛选后全部结果，不限当前页，保留可见字段与数据权限（COMP-Q-010）。无获奖公示同样展示，获奖作品数为0，正文说明无获奖。
