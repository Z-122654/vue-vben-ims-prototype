# 附件读取与表单操作保护验证

日期：2026-10-27。确认依据：SRC-28；对应 COMP-REQ-006、COMP-REQ-019，沿用 COMP-AC-019、COMP-AC-023 等既有场景编号。

## 实施范围

- 活动附件和申报附件同步读取数量到主表单，读取未完成时显示提示并禁用保存、提交／发布，操作方法再次校验。会改变可编辑状态的撤回申报、取消活动同时受保护。
- 关闭、右上角关闭、Esc、离开列表及刷新复用弹窗关闭保护。即使只有尚未读完的附件，也提示是否取消读取；继续填写保留任务和输入，确认放弃先取消再恢复已保存内容。
- 取消、组件卸载或转只读时终止 FileReader，并使原批次回调失效；已读完但尚未合并的任务也不能迟到写回。读取失败释放名额和保存拦截，可以重新选择。
- 附件继续选填；已有附件数量、大小、格式、公开范围及访问权限保持。未调整数据结构、迁移历史资料、接入真实接口或提交代码。
