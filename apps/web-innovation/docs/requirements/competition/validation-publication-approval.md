# 公示多人领导会签验证

日期：2026-11-05。依据：[SRC-34、COMP-REQ-031](overview.md)、[活动明细 COMP-AC-083～089](pages/activity-detail.md#公示领导会签src-34comp-req-031)。本记录是本轮验证，历史直接发布相关记录保留，不视为当前发布规则。

## 本轮实现

- 活动信息新增审批人设置，多选公示审批人；跨部门、提交人及参赛／专家身份兼任均允许。
- 保存名单、正文及人员配置后提交；并行全员同意自动公示，任一驳回结束整轮。管理员可撤回重提，每轮所有审批人重新处理。
- 活动中心仅当前待处理人显示“审批”入口。同一活动明细显示同意、驳回和流程图；基本信息、材料及正式评审记录只读，不授予管理或材料审核权。
- 本轮提交快照、审批记录及人员保存于现有本地存储；初次审批仍为待公示，更正审批保留已发布版本。末票与新公示一起保存，已结束活动更正不恢复阶段。
- 旧已公示数据不补造历史；以独立演示包追加五组虚构记录，名称均以“领导会签演示”开头，分别为待提交、多人审批中、审批驳回、审批撤回和更正审批中。

| 场景 | 观察结果 |
