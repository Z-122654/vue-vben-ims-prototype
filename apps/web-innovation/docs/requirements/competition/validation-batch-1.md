## 已实施范围

- 发布活动、开启／完成评审、结束活动成功时自动记录对应实际时间；公示日期取成功发布时间。失败操作不产生时间或不完整任务。
- 草稿人工设置报名截止和计划评审截止；对应阶段可填写原因调整计划期限，保留旧值、新值和原因。报名截止当天仍可报名，之后才可开启评审；评审逾期提示但不强制阻止评分，状态均由管理员手动推进。
- 新申报仅从活动中心列表行进入，活动带入只读；本部门负责人、参赛部门范围、填报归属均在页面和保存／提交处校验。管理员或专家兼任填报人时适用同样规则。
- 管理操作按活动组织单位与管理员授权组织范围判断；范围外管理员仅取得普通浏览或本人任务／申报权限，不取得内部管理权限。
- 专家候选覆盖全部演示人员、允许跨部门；开启评审检查审核通过项目的填报人与负责人整体回避，成功后生成项目×专家任务并锁定名单。各任务只能由对应人员评分。
- 退回记录仅按专属补交期限修改／重提，不与普通报名期限取任一有效。管理员可填写原因延期或终止；终止保留资料和历史，不参评、不阻塞开启；待审核／退回仍须处理完。
- 旧演示数据保留；新增实际时间仅从明确的历史动作补齐，缺历史不套用旧计划日期、不补造发生时间。旧负责人不自动改写；再次编辑保存时按本部门规则校验。

## 范围与限制

- 以上是本地原型规则与交互验证，不代表真实 IMS 服务端鉴权、数据库或文件权限已实现。
- 完整流程的完成评审、公示、结束时间及部分边界主要由自动化测试验证；浏览器未逐一走完所有专家任务和全部公示场景。
- 本批不重复执行用户原 `.doc` 文件上传验收，不重置原有浏览器数据。
- 附件拟公开与审核确认、零获奖公示／结果更正、删除限制／取消原因、正式证书、历史快照、统计／筛选导出、评分精度及剩余表单化差异继续按 D-08～10、D-12～15 跟进。已确认需求不等于这些事项已实现。
