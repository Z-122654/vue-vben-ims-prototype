# 专家与参赛身份前置校验验证

日期：2026-10-27。依据：SRC-30。关联：COMP-REQ-004、005、007、008、021、022；COMP-AC-047、075～078。

## 本轮规则

- 活动中心仍按部门、状态、计划期限提供行申报入口；本活动已选专家的按钮禁用并说明原因，直接新建也被限制。全局演示角色、其他活动的专家身份不替代活动级名单检查。
- 负责人仍只选登录人本部门，本活动已选专家禁用并标注原因。符合原编辑资格的记录可保存冲突草稿；提交和重提按最新名单强校验填报人和负责人，失败保持原记录、历史及时间。
- 专家配置禁用本活动待审核、退回修改、审核通过项目的填报人和负责人；草稿、撤回、终止不占用身份。保存活动及保存专家名单均再次校验。
- 旧冲突可从已选名单移除，既有项目不自动退回、终止、删除或改变人员；审核通过和开启评审保留最终拦截。开启后锁定规则及每位专家评全部通过项目的规则不变。
